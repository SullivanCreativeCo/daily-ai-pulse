Do more with the same. Not the same with less.

If your AI budget keeps climbing every time you want more capability, that's not the only path anymore. Somebody just showed a cheaper one.
LI . NO. 03
Salesforce just gave an AI agent a name, Hunter, and a job. Rescue at-risk deals before the quarter ends. Not answer a question. Not summarize an email. Run the whole thing for days, build its own plan, and only come back when it actually needs a human to decide something.

That's not a chatbot anymore. That's a job description.

For years the pitch on AI tools was it saves you time on a task. The pitch just changed. Now it's it holds a goal and works it while you're doing something else.

Small businesses feel this shift last, usually. But the tools trickling down from Salesforce's playbook always do, eventually, at a fraction of the price.

So the real question isn't whether you'll get an agent like Hunter someday. It's what job you'd actually trust one to run without checking in every hour.

AI launches & news

  • DeepSeek V4.1 Flash - The Register / NeoTeo DeepSeek shipped a model with 763 billion parameters that needs way less GPU memory than a model that size should need. The trick: about a quarter of those parameters are "N-gram" weights that live in cheap system memory instead of expensive GPU memory, doing pure lookup instead of heavy computation. Alibaba's Qwen team did basically the same thing days later. When two labs land on the same architecture idea in the same week, that's not a coincidence, that's the new default showing up. https://www.theregister.com/ai-and-ml/2026/09/11/deepseeks-new-model-sets-a-template-for-powerful-llms-that-run-lean/5295715

  • Gemini lands on Windows with Alt+Space - Shattered.io Google finally shipped a real desktop app for Windows, not a browser tab pretending to be one. Hit Alt+Space from inside anything, spreadsheet, code editor, whatever, and Gemini pops up over it. Feels small. It's not. A billion Windows machines just got a native front door to Gemini, right as Copilot already lives in the taskbar and ChatGPT's desktop app is already on millions of PCs. This is a distribution fight now, not a model fight. https://shattered.io/gemini-app-windows-launch-alt-space-2026/

  • OpenAI launches ChatGPT for Financial Services - TechNode Built with Morgan Stanley and Evercore as design partners. It pulls in PitchBook, LSEG News, and Daloopa data and turns it into pitchbooks and models in a bank's own template. This is the pattern to watch. OpenAI isn't selling "a smarter chatbot" to industries anymore. It's selling a version of ChatGPT that already knows your data providers and your PowerPoint template. That's a much bigger moat than a benchmark score. https://technode.global/2026/09/12/openai-chatgpt-financial-services/

Enterprise AI moves

  • Salesforce's agents now work for weeks, not minutes The new "long-horizon runtime" lets an agent named Hunter take a goal like "save my at-risk deals before quarter end" and just work it. Days. Weeks. It builds its own plan and only comes back when it needs a decision. For anyone selling AI into small businesses, this is the bar shifting again. A chatbot that answers a question is table stakes now. The pitch has to be "this thing keeps working after you go home."

  • OpenAI's new Agents API bundles the whole harness - InfoWorld One API call and you get the orchestration, the sandbox, the memory, all of it, hosted by OpenAI. Analysts are already calling out the trade. Less engineering work, way more lock-in. If you're a small shop building on this, that's the tradeoff to actually think through before you build. Fast to ship, hard to leave.

  • Sidetrade bets the opposite direction - The Datatech Times Sidetrade's new agent framework runs on hardware they own, not rented tokens from OpenAI or Anthropic. Their pitch to CFOs: predictable cost, your data never leaves your building. Two totally different bets on the same problem, same week. One says let the platform hold everything. The other says own your own compute. Worth watching which one wins with buyers.

New harnesses & tools

  • TrueFoundry launches TrueForge, open source, model-agnostic Same category as OpenAI's new Agents API, except open source and built to not lock you into one model provider. Claims up to 50% lower cost by routing calls through their own gateway instead of one vendor's. If you've been burned by a platform that only plays nice with itself, this is worth a real look before you commit to anything proprietary.

  • NVIDIA PAIR spreads AI work across your own machines - InfoQ Got a couple computers on your network? PAIR lets them share the load on local AI tasks instead of maxing out one GPU. In NVIDIA's demo, three machines working together cut completion time roughly in half. This is for the local-AI crowd specifically, but the idea is creeping into enterprise too. Don't rent all your compute, use what you already own.

  • Devin learns to test its own work - OpenAI Cognition's Devin now uses GPT-6 Astra to actually run the software it writes and show you a recording plus a report of what passed and what didn't. Their words: the goal is engineers reviewing less code and shipping more. That's the real unlock. Not "AI writes code faster." AI proves the code works before a human even looks at it. That changes what code review is for.
