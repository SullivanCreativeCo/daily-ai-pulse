New harnesses & tools

  • Argus - Microsoft / Shanghai Jiao Tong University Open source agent runtime built to run for days, not minutes. 1,548 hours across 27 research campaigns, holding 95 to 98% uptime the whole way. Work splits into Campaigns and Missions with separate planner, engineer, and reviewer roles so the agent can't just take the lazy answer and call it done. This is where long-running agent work is headed. Less one prompt one output, more a small team of roles checking each other for days at a time. [https://www.kucoin.com/news/flash/microsoft-and-shanghai-jiao-tong-university-open-source-argus-1548-hour-autonomous-research-system]

  • CUA-Lite - UC Berkeley Unifies the pile of separate computer-use-agent repos (sandboxes, datasets, eval, training) into one interface. Runs the OSWorld benchmark in a lightweight container instead of a full VM, 4.6x more parallel desktops, same scores as the real thing. If you're building or testing anything that has to touch a real screen, this collapses a week of plumbing into one command. [https://tradepoint.io/uc-berkeley-researchers-release-cua-lite-an-open-platform-unifying-sandboxes-data-evaluation-and-rl-for-computer-use-agents/]
