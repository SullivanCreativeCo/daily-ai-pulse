New harnesses & tools

  • DeepSeek Harness - open source, MIT license A modular alternative to Claude Code where practically every part of the agent runtime is a swappable plugin. Free code, no lock-in. If you've been building workflows on one harness, this is worth a look just to see what you'd lose or gain by not being locked to one vendor's opinions.

  • Arcee NAC - Arcee AI, open source A harness built for work too big for one session. An orchestrator plans and hands off pieces to "threads" that come back with structured summaries, so long jobs don't blow up your context window. This is the pattern for anyone doing bigger multi-step builds with an agent. Stop trying to cram everything into one conversation. Delegate the pieces and let them report back.

  • Fireflies Email Assistant - Fireflies.ai Fireflies already sits in 20 million people's meetings. Now it's triaging inbox, drafting replies, and following up on threads that went quiet, using context from meetings you already had. This is a real, sellable pain point for a small business owner drowning in email. Worth studying the pitch, not just the feature list.
